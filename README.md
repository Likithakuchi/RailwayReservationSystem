Railway Reservation System
🚆 Project Overview

The Railway Reservation System is a Full Stack web application that allows passengers to search trains, book tickets, manage reservations, and view booking history. The system also provides an admin panel to manage trains, routes, schedules, and users.

This project simplifies the railway ticket booking process by providing a secure and user-friendly interface.

✨ Features
👤 User
*User Registration & Login
*Secure Authentication
*Search Available Trains
*View Train Details
*Book Train Tickets
*Cancel Bookings
*View Booking History
*Update User Profile

🛠 Admin
*Admin Login
*Add New Trains
*Update Train Information
*Delete Trains
*Manage Routes
*Manage Schedules
*View All Bookings
*Manage Users
